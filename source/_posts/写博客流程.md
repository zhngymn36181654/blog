## 一、**设置**

### 图片管理

这是新手最常踩的坑。把图片随便放，以后迁移、备份、引用都会是噩梦。

**强烈推荐使用Hexo 的“资源文件夹”（Asset Folder）功能。**

**1. 什么是资源文件夹？**
为每篇博客文章创建一个与文章文件同名的文件夹，专门用来存放该文章所有的图片、附件等资源。

**2. 如何开启？**
在你的 Hexo 博客根目录的配置文件 `_config.yml` 中，找到并修改以下设置：

```yaml
post_asset_folder: true
```



问题来了，hexo默认不能识别相对路径`![title](image1.jpg)`,网页加载图片失败。

因此，需要安装一个插件

```
npm install --save hexo-filter-pathfix
```

## 二、一般流程

1. 创建博客文章

   ```
   hexo new "我用hexo写博客的一般流程"
   ```

2. 打开`/source/_posts/我用hexo写博客的一般流程.md`文件,在 Front-matter 中设置好 `categories` 和 `tags`。

3. 用 Typora 编辑生成的文件

4. 写好的博客文章，先在本地测试,检查文章的排版，图片是否正确。

   ```
   hexo clean && hexo g && hexo server
   ```

5. 正式部署

   ```
   hexo clean && hexo g
   ```

6. 同步`github`，`vercel`会自动部署。

   ```
   git push origin main
   ```
